## 2. Visual Novel Game Output & Asset Licensing Boundary (`GPT-57 / CL-57`)

To protect visual novel creators and commercial/indie game developers using MooVN Studio:

1. **Creator-Owned Content**: Project files (`.mpvn`), chapter packages (`.msvn`), YAML/JSON scene scripts, dialogue text, illustrations, layered character sprites, audio tracks, and video assets created or imported by the user remain the sole property of their respective authors and may be distributed under any license chosen by the creator (including proprietary/commercial licenses).
2. **Standalone Exported Game Packages**: When MooVN Studio exports a standalone HTML5 or platform game package, the user's narrative data and assets are packaged as independent data payloads. Using MooVN Studio to author and export a visual novel does **not** require the creator's original story, artwork, or music to be licensed under GPL-3.0.
3. **Modifications to MooVN Engine / Studio Source**: Any modifications or derivative works of the MooVN Studio editor or the MooVN Engine runtime source code itself remain governed by `GPL-3.0-only`.
