# MooVN (`v0.1.0-dev`)

MooVN 是开发中的视觉小说创作工具，包含 React/TypeScript 工作台、Rust 引擎和 Web 入口。当前版本尚未完成安全、运行时一致性与安装版验收，不应视为正式发布。

- [`MooVN Studio/`](./MooVN%20Studio/)：编辑器、场景预览及实验性 HTML 导出。
- [`MooVN Engine/`](./MooVN%20Engine/)：Rust 运行时和实验性 C ABI/C++ 接口。
- [`MooVN Web/`](./MooVN%20Web/)：官网与浏览器编辑器入口。

## 文件格式与已知限制

| 格式 | 内容和限制 |
| --- | --- |
| `.mpvn` | JSON 工程封套；目前**没有校验和**。含独立外置素材引用的工程暂不能作为单一可移植文件导出。 |
| `.msvn` | 可导出的章节数据，采用 MooVN LZ77 或未压缩封套；HTML 播放器尚不能加载该章节包。 |
| `.html` | 单文件实验性播放器，节点和特效支持范围有限；导出检查不能证明脚本语法或整部作品可运行。 |

引擎存档使用 **64 位 FNV-1a** 发现部分意外损坏；它不是密码学校验，任何能够修改文件的人也能重新计算该值，不能防篡改。各播放器/引擎的存档暂不互通。1.0 工程首次导入会按提示迁移角色锚点；检查后需手动保存 1.1，源文件在保存前不会被改写。

工作台菜单支持简体中文、繁体中文、英语和日语，许多面板内容仍为中文。`moovn.*` API 语法改写为实验功能，不是 C#/C++/Rust 编译器，也不能保证目标代码可运行。Live2D/Spine 运行时与正式安装包尚未提供。L1 眨眼、口型依赖实际图层。

## 开发

需要 Node.js **22.6 或更新版本**和 npm。当前两端共用 Studio 的测试及源码：干净检出后须在 `MooVN Studio/` 和 `MooVN Web/` 分别运行 `npm ci`，再在两目录运行 `npm test` 和 `npm run build`。Rust 引擎使用 `cargo test`；桌面端还需 Tauri 对应平台构建依赖。
