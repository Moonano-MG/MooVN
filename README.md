# MooVN (`v0.1.0-dev`)

MooVN 是开发中的视觉小说创作工具，包含 React/TypeScript 工作台、Rust 引擎和 Web 入口。当前版本尚未完成安全、运行时一致性与安装版验收，不应视为正式发布。

- [`MooVN Studio/`](./MooVN%20Studio/)：编辑器、场景预览及实验性 HTML 导出。
- [`MooVN Engine/`](./MooVN%20Engine/)：Rust 运行时和实验性 C ABI/C++ 接口。
- [`MooVN Web/`](./MooVN%20Web/)：官网与浏览器编辑器入口。

## 文件格式与已知限制

| 格式 | 内容和限制 |
| --- | --- |
| `.mpvn` | JSON 工程封套；新版含 SHA-256 损坏自检（不是防篡改），旧文件无校验并会提示。含独立外置素材引用的工程暂不能作为单一可移植文件导出。 |
| `.msvn` | 可导出的章节数据，采用 MooVN LZ77 或未压缩封套；新版含 SHA-256 损坏自检（不是防篡改），旧包无包级校验。HTML 播放器尚不能加载该章节包。 |
| `.html` | 单文件实验性播放器，节点和特效支持范围有限；导出检查不能证明脚本语法或整部作品可运行。 |

文件封套、校验边界和旧格式兼容说明见 [格式文档](./MooVN%20Studio/FORMATS.md)。引擎存档使用 **64 位 FNV-1a** 发现部分意外损坏；它不是密码学校验，任何能够修改文件的人也能重新计算该值，不能防篡改。各播放器/引擎的存档暂不互通。1.0 工程首次导入会按提示迁移角色锚点；检查后需手动保存 1.1，源文件在保存前不会被改写。

工作台菜单支持简体中文、繁体中文、英语和日语，许多面板内容仍为中文。`moovn.*` API 语法改写为实验功能，不是 C#/C++/Rust 编译器，也不能保证目标代码可运行。Live2D/Spine 运行时与正式安装包尚未提供。L1 眨眼、口型依赖实际图层。

随机分支、switch-case 多路路由和选项条件表达式尚未实现，不能作为已支持功能使用。旧工程仍可打开并保留原数据；预览遇到这些内容会暂停，工程图报错，相关生成的 JS/TS 函数执行时会报错，HTML 导出会阻止。检查器可明确移除旧选项条件并撤销，但移除会改变分支含义；无条件玩家选项在预览中仍可使用。

Studio/Web 预览回退保存当前已模拟的变量、好感、角色属性、词条、文字速度和限时剩余；读档后此前的回退历史会清空。旧预览存档未完整记录词条、文字速度或限时状态，读取前会提示并要求确认；损坏或较新版本的槽位保留原数据。打开预览或刚读档不会立刻覆盖已有自动存档，推进剧情或开始新游戏后会更新。预览仍未实现全部节点和脚本，不能据此保证其他运行时行为一致；跨标签页存档竞争也尚未解决。

## 开发

需要 Node.js **22.6 或更新版本**和 npm。当前两端共用 Studio 的测试及源码：干净检出后须在 `MooVN Studio/` 和 `MooVN Web/` 分别运行 `npm ci`，再在两目录运行 `npm test` 和 `npm run build`。分支安全和预览状态浏览器回归可在两目录分别运行 `npm run test:branches:e2e` 和 `npm run test:preview-state:e2e`，需要可用的 Chromium（可通过 `MOOVN_CHROMIUM_PATH` 指定）。Rust 引擎使用 `cargo test`；桌面端还需 Tauri 对应平台构建依赖。
