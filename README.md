# MooVN 视觉小说编辑器与跨平台引擎

采用 **TypeScript + Tauri 2 + Pixi.js + YAML** 构建的现代视觉小说可视化编辑器与运行引擎。

## 核心特性

1. **Dify 式工作流与多语言混合编程**：
   - 支持类似 Dify 的节点工作流编排（包含**开始、背景、角色、音效/BGM、对话、分支/选项、Lua/Teal/Python/TS 脚本、结局**等节点）。
   - 同时提供**可视化代码块（Visual Code Blocks）**与**纯代码 IDE**，内置 **Python、TypeScript/JavaScript、Lua、Teal** 四种语言开发与运行时支持。
   - 支持**蓝色视觉小说模板模式**与**无模板 Godot 式通用 2D 可视化编辑器模式**一键切换。
2. **黑白双主题界面**：
   - 支持**黑色风格（Dark Theme）**与**白色风格（Light Theme）**实时切换。
3. **章节 > 场景 文件管理器与 YAML 双向同步**：
   - 严格采用 `章节 > 场景` 层级管理，就算未修改人物与背景、仅修改对话也独立算作一个场景。
   - 每个场景支持可视化拖拽立绘调整坐标/缩放/表情，并实时双向同步与导出 `.yaml` 配置文件。
4. **角色系统、章节系统与多剧情线/多结局**：
   - 角色系统内置**好感度（Affection）**，并支持自由添加任意**自定义属性**（数值、文本、布尔值）。
   - 支持基于好感度或选项分支动态进入不同剧情线与多结局（TRUE / GOOD / NORMAL / BAD END）。
5. **完整的「蓝色模板」视觉小说游戏**：
   - **主菜单**：左侧深蓝色背景选项栏（依次为：**开启新游戏、读取存档、设置、关于、退出游戏**），中右侧为主视觉立绘背景，左与中之间设有**深蓝到黑的毛玻璃模糊过渡层**。
   - **设置与互通存档/读档系统**：包含**通用设置、高级设置、读档、存档、退出到菜单**。读档与存档完全互通，采用标准视觉小说布局：上中三行共 **6 个档案槽位（3行×2列）**，下方为 **`Auto`、`快速`、`1` ~ `0` 共 12 个文件夹选项卡**（总计 72 个独立档案位）。空槽位显示「空档案」，已保存槽位显示场景缩略图（动画场景捕获动画开头帧）并在下方显示保存时间。
   - **游戏内交互界面**：下方为黑色背景+深蓝边框对话框，底部配有**后退、自动、快进、隐藏、设置**。
     - **后退**：退回上一个场景。
     - **自动**：根据文字显示速度自动推进。
     - **快进**：严格校验已游玩进度（例如已玩过场景 10，开启新游戏从场景 1 可快速跳过至场景 10，抵达场景 10 后由于后续场景未游玩自动停止快进）。
   - **游戏内分支选项**：位于对话框左上方，未超出屏幕宽度绝不换行；采用黑色背景+深蓝边框，鼠标悬浮时选项文字左侧亮起浅蓝色指示条。
6. **跨平台支持 (Tauri 2)**：
   - 必选支持 **Windows** 与 **Android**，并内置 **iOS** 与 **macOS** 可选构建支持。
