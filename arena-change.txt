A. 代码漏洞与缺陷（14 项）

[C01 ← SEC-01 | P2 | 部分变化] FNV 防篡改说法。
证据：README.md:17、S/SECURITY.md:32–35、E/src/save.rs:102–115 已明确 FNV 仅发现部分意外损坏、非认证；Rust v2 不覆盖 timestamp，S/src/lib/vnRuntimeCore.ts:63–67 同样说明局限。影响：不能据此承诺抵御改档，也不能声称各播放器均有该校验。
建议/验收：全仓扫描并人工审阅相关正反表述；改写后修改内容并重算校验、单改时间戳、缺值和正常值均有明确预期；实际播放器接线后再验收。

[C02 ← SEC-02 | P1 | 仍存在] TS/Rust canonical 互通。
证据：S/src/lib/vnRuntimeCore.ts:58–105 将属性/线索折入变量并按 JS UTF-16 排序；E/src/save.rs:73–99 使用 Rust 字符串排序和自身字段。README/SECURITY 已承认 v2 不完全互通；同一 FNV 算法不等于同一 payload。
建议/验收：定义有版本的完整编码、键顺序、转义与迁移；TS/Rust 共用 ASCII、中文、补充平面字符、分隔符和空值 golden vectors，逐字节互验；不可笼统断言所有中文键都会分叉。

[C03 ← SEC-03 | P1 | 部分变化] 工程和章节包校验。
证据：#32 的 S/src/lib/mpvnFormat.ts:102–123,188–208 和 assetCompressionEngine.ts:386–397 新增覆盖封套内容的无密钥 SHA-256；旧包返回 legacy-unchecked，S/FORMATS.md:40–51 已披露可重算或去掉版本字段降级。影响：原先“新版无包校验”不再成立，但自检不是来源认证、签名或防恶意篡改。
建议/验收：保留真实警告；新旧包、元数据变化、缺校验、被重算和显式旧版导入分别测；若要认证另行设计签名与信任来源，不把 SHA 说成防篡改。

[C04 ← SEC-04 | P1 | 仍存在] 多端条件语义。

[C05 ← BUG-05 | P1 | 仍存在] API 参数转义与嵌套。

证据：S/src/components/PreviewPlayer.tsx:864–880 的绝对选项层未限定高度/滚动；S/src/lib/gamePackager.ts 也有绝对选项布局。旧版浏览器长选项顶部曾分别约为 -224px（预览）、-171px（HTML），当前未复跑。
影响：按钮可能被裁剪且无法点击。建议/验收：限制容器可用高度并允许纵向滚动，文字正常换行；320×568、900×560、超长多项、键盘及触控均能访问每项。

[N17 | P1 | 静态风险] C++ binding 将不可信字符串拼进 DSL。
证据：E/cpp/include/moovn_api.hpp:42–54 把 bg_id、speaker、line 直接插入带引号的脚本；E/src/translator.rs:409–435 自行拆参数。引号/换行可能改变参数或引入额外 MooVN 指令；没有证据表明可执行系统命令。
影响：文本与命令边界混淆，可能产生非预期的引擎操作。建议/验收：直接提供结构化 C ABI 或严格序列化/解析；含引号、换行、反斜杠及伪指令的输入只能作为字面数据，验证不会新增 IR 操作。

[N18 | P1 | 仍存在／待验证] FFI 默认存档只在内存、生命周期未封装。
证据：E/src/ffi.rs:13–15 调用 MooVNEngineRuntime::new，E/src/runtime.rs 的 new 使用内存 SaveManager；桌面 Tauri 的 with_save_dir 是另一条路径。E/bindings/csharp/MooVN.Engine.cs:43–67 全局 Handle 可写、自动创建但无自动释放；并发/释放风险仅静态分析。
影响：宿主重启后不能假设 FFI 存档仍在，错误句柄或并发调用风险需定义。建议/验收：提供显式持久目录构造、所有权和线程约束、安全封装；跨进程重开、并发、重复释放和错误状态在各语言宿主验证。

[N19 | P1 | 静态风险] 导入设置缺完整 schema/限额。
证据：S/src/components/ProjectLauncher.tsx:191–205 只 JSON.parse 并检查 workspaceRootPath 就把对象写入设置/状态；:653–689 随后读取嵌套 defaultGameSettings 字段。影响：结构畸形或超大设置可能使界面异常/写入无效配置；本轮未进行浏览器破坏性测试。
建议/验收：导入前按完整 schema、大小和数值范围验证，并对失败保留旧设置；缺字段、额外字段、极值、超大文件与取消均有测试。

A. 可靠窗口和停靠（未验收）

B. 不是整张图上下跳的动态人物（未验收）
- L0：只有单张立绘时静态显示，脚底为稳定锚点；没有实际图层或遮罩时不伪造眨眼、口型或全图呼吸。缺眼/口层在角色和节点检查器列出并允许上传。
- L1：保留现有 ImageAvatar 的 body、眼、嘴、眉、前后发、expression、眨眼/口型、工厂、归一化坐标和 dt≤50ms 等七步能力。使用实际导入的局部胸腹/衣物遮罩及独立上层，只对遮罩内局部像素做轻微、可关闭的形变；底图和脚底不位移、不整图 scaleY。没有遮罩就保持静态，不以透明蒙版假装完成。

import { lzCompressBytes, lzDecompressBytes } from './src/lib/assetCompressionEngine.ts';
let seed = 0x12345678;
const data = new Uint8Array(1024 * 1024);
for (let i = 0; i < data.length; i++) {
  seed ^= seed << 13; seed ^= seed >>> 17; seed ^= seed << 5; data[i] = seed & 255;
}
const start = performance.now();
