三、本轮实际改动及界限
- .mpvn 新封套 v2、.msvn 新封套 v2 均使用覆盖包内容的无密钥 SHA-256；修改内容或缺失 v2 校验信息会报错。旧 .mpvn 解析标记 legacy-unchecked，导入/桌面最近文件路径提示并要求手动保存；旧 .msvn 解析返回 legacy-unchecked，目前没有可加载章节包的 UI/HTML 播放器。
- SHA-256 此处不是签名：攻击者可重算或移除校验后降级为旧格式；文件来源未认证。旧兼容只覆盖现有测试样本，不代表所有历史工程兼容。外置素材仍不能作为单一可移植包导出。
- .msvn 解压有压缩/解压字节上限、压缩级别和包元数据检查；拒绝非节点、重复关键 ID、章节 ID/解锁信息不一致与危险键。章节依赖、跨章节语义、恶意大文件性能及运行时挂载仍需进一步验证。
- Engine CLI 只运行固定内存示例，--help 现说明不加载 .mpvn/.msvn、不编译宿主语言，未知参数失败；输出不再称语言已翻译。运行时诊断丢弃问题仍在。
- Engine 真实磁盘故障测试中，修前写入、备份、删除失败都会假报成功；本地修改使错误向 Rust runtime/C ABI 和桌面桥返回，失败不更新内存，失败后停止执行后续指令，此前指令不回滚。重载全成功后才替换内存。名称清洗碰撞现在拒绝，不是支持两个碰撞名。备份复制仍非原子，跨进程 TOCTOU/丢更新、目录同步、崩溃恢复以及 Windows/macOS 行为未验证。新写 v2 存档会转义变量键的 `.`；旧版本已写出且包含未转义点的存档可能校验失败，尚无自动恢复。FFI 的零条指令与失败均返回 0，诊断不充分。公开 Rust API `create_save` 与 `delete_save` 改为 `Result`，调用方须迁移。脚本错误在 UI 保持可见；原生 Tauri 整条链路尚未构建验证。
- 本地 ci.yml 与 build.yml 仅允许手动；本地 build.yml 新增 Linux 桌面 job、Engine 输出和各平台产物缺失失败检查，iOS 不再以仅 Xcode 工程冒充应用。工作流仅完成静态检查，尚未实际在 GitHub 运行；签名/公证和 Apple 设备安装未验证。
- 用户质问的 Actions run 40662318416 是 v0.1.0-dev 合并时 push 触发的自动 Quality checks，仅安装/跑前端测试，构建与原生任务 skipped；不是全平台构建。远端 disable 与用户授权的手动 build dispatch 均返回 HTTP 403，远端自动检查仍未关闭，全平台构建未启动。本地修复尚未合并，远端原工作流仍可能自动运行。
- 由于 build job 只允许 v0.1.0-dev，远端若现在手动构建也只会构建远端当前基线，不包含本工作区未合并变更；不得为绕过限制直接改 main 或在 P0 未清零时合并。
